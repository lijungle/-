# MSPM0G3507 小车使用说明

## 1. 当前固件功能

当前版本支持可设置距离、速度和每米编码器计数的直行模式，以及顺时针方形路线。KEY4（PB21）只在停车页切换路线模式。

## 2. 当前接线

| 外设信号 | MSPM0G3507 引脚 | 说明 |
| --- | --- | --- |
| 左电机 AIN1 / AIN2 | PB4 / PA23 | AT8236 左路 PWM |
| 右电机 BIN1 / BIN2 | PB1 / PA18 | AT8236 右路 PWM |
| 左编码器 A / B | PA17 / PA24 | A 相中断，B 相判方向 |
| 右编码器 A / B | PA15 / PA16 | A 相中断，B 相判方向 |
| KEY1 / KEY2 / KEY3 / KEY4 | PA26 / PA25 / PA12 / PB21 | 低电平有效，内部上拉 |
| JY61P TX / RX | PB3 / PB2 | UART3，115200、8N1 |
| DX-GP24 TXD / RXD | PB7 / PB6 | UART1，115200、8N1；GPS TXD 接 PB7 |
| ESP32 RX / TX | PB15 / PB16 | UART2，115200、8N1，双方使用 3.3V 逻辑电平并共地 |
| OLED SDA / SCL | PA28 / PA31 | SSD1306，I2C 地址 0x3C |
| SWDIO / SWCLK | PA19 / PA20 | 下载和调试 |

电机电源按照 AT8236 和电机规格接入。编码器、JY61P 和 OLED 使用兼容的 3.3V 电平，所有模块共地。下载调试时先关闭电机电源并架空车轮。

## 3. 按键操作

| 状态 | 操作 | 功能 |
| --- | --- | --- |
| 停止 | 短按 KEY4 | 切换直行/方形模式 |
| 停止 | 短按 KEY1 | 以当前位置和航向为起点启动当前模式 |
| 停止 | 短按 KEY2 | 进入设置 |
| 设置 | 短按 KEY4 | 距离→速度→每米计数循环 |
| 设置 | 短按 KEY1 / KEY3 | 增加 / 减少当前值 |
| 设置 | 短按 KEY2 | 进入 GPS 页面 |
| GPS 页面 | 短按 KEY2 | 返回停车页面 |
| 行驶 | 按 KEY3 | 立即停止并刹车 |

距离范围为 1～10 m，默认 1 m；速度范围为 5～30，默认 20；每米计数范围为 1000～10000，步进 10，默认 3250。参数只在本次上电运行期间保留，断电或复位后恢复默认值。方形模式每条边使用距离设置值，连续四边后顺时针转回起始航向并停车。

## 4. OLED 显示

- 普通运行页第一行显示当前状态和路线进度，第二行显示当前前进距离和目标距离，例如 `0.42/1m`，第四行显示 JY61P 航向。
- GPS 页面第二行显示纬度（N/S），第三行显示经度（E/W），第四行显示定位质量 Q 和 HDOP。
- 停止页显示当前直行/方形模式；设置页显示当前项，第三项为每米计数。
- GPS 页面显示纬度、经度、定位质量 Q 和 HDOP；未收到有效 NMEA 数据时显示 `NO DATA`，接收环形缓冲区溢出时显示 `OVF`。

GPS 页面只在停车时进入，不影响电机控制。DX-GP24 默认输出 NMEA 数据，使用 115200、8N1。定位质量 Q 来自 GGA：0 表示无定位，1 及以上表示已获得定位；HDOP 越小通常表示水平定位几何条件越好。

串口资源分配为：UART0/PA10-PA11 预留 MaixCAM，UART1/PB6-PB7 接 DX-GP24，UART2/PB15-PB16 接 ESP32（小智），UART3/PB2-PB3 接 JY61P。GPS 接收使用 512 字节环形缓冲区，中断只入队，主循环限量解析，不使用阻塞等待。

OLED 刷新由主循环分包进行，控制周期为 10 ms。若 OLED 无显示，先检查 3.3V、GND、SDA、SCL 和 0x3C 地址，再复位重新初始化。

## 5. 运行参数

| 参数 | 当前值 |
| --- | --- |
| 编码器标定 | 3250 计数/米 |
| 左电机死区补偿 | 8% |
| 右电机死区补偿 | 8% |
| 左速度 PID | Kp=0.8，Ki=0.15，Kd=0 |
| 右速度 PID | Kp=0.8，Ki=0.15，Kd=0 |
| PWM 频率 | 10 kHz |

死区补偿用于提高低速起转能力，左右电机暂按相同 8% 使用，尚未分别实测。速度设置值不是直接的米每秒，实际速度会受电池电压、负载、轮胎打滑和 PID 调节影响。

JY61P 航向范围约为 -180°～+180°，左转为正、右转为负。程序按角度跨越 ±180° 的方式计算误差；航向是相对角度，长时间运行会有漂移。

## 6. 直行控制流程

1. 停止状态按 KEY1，程序记录当前编码器计数和 JY61P 航向。
2. 左右轮平均增量按当前每米计数换算为位移，并结合航向更新局部位置。
3. 航向控制修正左右轮目标速度，速度 PID 再调整左右 PWM。
4. 剩余距离较小时自动减速。
5. 到达目标距离附近后停止并保持刹车。

编码器方向已经按当前电机安装方向换算，正常前进反馈应为正。如果架空测试时计数方向相反，应先检查电机和编码器接线，不要通过增大 PID 参数解决方向错误。

## 8. 首次实车检查

- 先将距离设为 1 m、速度设为 5～10。
- 架空车轮按 KEY1，确认两轮方向一致且松开后能刹车。
- 在平整地面测试无障碍直行，检查是否在目标距离附近停止。
- 逐步提高速度；若出现左右摆动，先检查编码器方向、机械阻力和 JY61P 安装，再调整控制参数。
- 测试过程中随时可以按 KEY3 停车，也应能立即断开电机电源。


## 9. ESP32 串口通信

本次只修改 MSPM0 固件。UART2 使用 115200、8 数据位、无校验、1 停止位，无流控。

- MSPM0 PB15（UART2 TX）接 ESP32 RX。
- MSPM0 PB16（UART2 RX）接 ESP32 TX。
- GND 接 GND。串口为 3.3V 逻辑，ESP32 按自身开发板规格供电。
- UART0/PA10-PA11 仍留给 MaixCAM，UART1/PB6-PB7 仍接 GPS，UART3/PB2-PB3 仍接惯导。

每 200 ms 发一条位置帧，结尾为实际换行字节 LF（0x0A）：

```json
{"type":"position","lat":31.2304,"lng":121.4737,"heading":90,"speed":0.8}
```

lat/lng 为 GPS 最近坐标（十进制度）；尚无坐标时为 0，失去定位后保留上次坐标。本协议没有定位有效性字段，接收端不能仅凭非零坐标断定实时定位有效。heading 为 JY61P 原始相对航向，约 -180°～180°，左转为正，不代表 GPS 真北方位角。speed 为左右编码器平均值按当前每米计数换算的 m/s，前进为正，后退为负，原地转向接近 0。

控制帧同样以换行结束，支持 CRLF：

```json
{"type":"control","cmd":"forward","speed":50,"duration_ms":500}
```

| cmd | 动作 |
| --- | --- |
| forward | 前进 |
| backward | 后退 |
| left | 惯导闭环原地左转 90° |
| right | 惯导闭环原地右转 90° |
| stop | 取消当前遥控或自动路线并刹车 |

运动命令必须包含上述四个字段，字段顺序不限。speed 为 0～100 的整数百分比，映射到 0～30 计数/10ms 的轮速目标，与菜单中的自动路线速度独立；50 对应 15 计数/10ms，按默认 3250 计数/米约为 0.462 m/s。speed 为 0 时停车。forward/backward 的 duration_ms 为 1～60000 毫秒，到期自动停车；left/right 使用惯导闭环转 90°，duration_ms 仅保留协议字段，最长 10 秒仍未到位则故障停车。

停止可只发送 `{"type":"control","cmd":"stop"}` 加换行。设置页和 GPS 页面禁止远程起动，KEY3 始终优先停车；惯导故障时禁止遥控起动并停止正在执行的动作。遥控时 OLED 第一行显示 `REMOTE`，退出动作后保留原来的直行/方形模式和设置参数，下一次自动路线由 KEY1 重新启动。

收发各有 512 字节环形缓冲区。中断搬运字节，主循环每次最多解析 128 字节；单帧最多 159 字节（不含 LF）。仅接受约定字段，错误 JSON、重复字段、未知命令和越界参数均丢弃。接收溢出或超长帧会丢弃至后续换行后重新同步；发送空间不足时丢弃整条位置帧，不发送半帧、不阻塞电机控制。断线后不会续期，最多执行完当前 duration_ms；需要更短停止时间时发送较短动作并定期续发。

架空车轮，先确认位置帧持续输出，再分别发送 100～500ms 的低速动作，检查五个方向、到期停车和 KEY3 停车，再落地测试。本次已完成主机自检、SysConfig 及 Keil 构建，尚未进行实车串口和电机验证。
