# AT8236 小车移植与直行控制说明

当前工程已回退到未加入超声波和红外避障的版本，以下传感器接线和避障描述不适用于当前固件。

底层参考 `New_TMX/8PIDTMX_MSPM0G3507_at8236(1)`，保留 car_smart 的速度 PID、模糊航向控制与 JY61P 协议解析。本版只保留可设置距离的直行控制，完整操作见 `使用说明.md`。

## 引脚与时序

| 外设 | 引脚 / 资源 | 配置 |
| --- | --- | --- |
| 左轮 AIN1 / AIN2 | PB4 / PA23 | TIMA1 CCP0 / TIMG7 CCP0 |
| 右轮 BIN1 / BIN2 | PB1 / PA18 | TIMA1 CCP1 / TIMG7 CCP1 |
| 左编码器 A / B | PA17 / PA24 | A 相双沿中断，B 相判方向 |
| 右编码器 A / B | PA15 / PA16 | A 相双沿中断，B 相判方向 |
| KEY1 / KEY2 / KEY3 | PA26 / PA25 / PA12 | 上拉，低有效 |
| KEY4 | PB21 | 上拉，低有效；停止时切换传感器检测页 |
| JY61P TX / RX | PB3 / PB2 | UART3，115200，8N1 |
| OLED SDA / SCL | PA28 / PA31 | I2C0，SSD1306，0x3C |
| 左 / 右 MH-B OUT | PB10 / PB11 | 低有效，20ms 消抖 |
| HC-SR04 Trig / Echo | PA7 / **PA27** | 10µs 触发，Echo 双沿测宽 |
| 控制节拍 | TIMG0 | 10ms 中断 |
| 超声波计时 | TIMG8 | 1MHz，16 位下降计数，不启用定时中断 |

新增四脚经 MSPM0G3507 引脚功能表检查均无 UART 复用。左右红外使用用户确认已引出的 PB10、PB11。PA19 是 SWDIO，Echo 使用 PA27。超声波供电 5V，Echo 必须经 10kΩ 串联、20kΩ 对地分压；MH-B 的供电、输出电压与低有效逻辑需按实物验收。

系统时钟 32MHz；PWM 分频 8、周期 400，为 10kHz。TIMA1 反相、TIMG7 非反相，沿用 AT8236 慢衰减关系；零输出两输入同高刹车。左右死区 8%，速度 Kd 均为 0。每米 3140 计数，左编码器符号 -1、右 +1，前进反馈为正。

## 代码边界

| 文件 | 职责 |
| --- | --- |
| `main.c` | 按键处理、10ms 控制、启动门槛、惯导超时、最终电机输出 |
| `control.c/.h` | 距离/速度设置、局部位置估算、直行与绕行状态机、停车原因 |
| `board_glue.c/.h` | PWM、编码器、按键、惯导快照、红外消抖、非阻塞超声波与障碍快照 |
| `jy61p.c/.h` | 角度/角速度协议与角度更新超时 |
| `oled_status.c` | 运行/设置/故障页面，分包刷新 |
| `oled_font_cn.h` | 固定中文 16×16 逐行点阵 |
| `empty.syscfg` | 引脚、定时器、UART、I2C、PWM、时钟配置源文件 |

位置采用左右平均增量除以 3140，并按相邻航向中间角投影。纵向位置控制终点，横移与对称原地转向不虚增纵向里程。沿原直线、绕行平行线和垂直横移线均修正位置及航向。

避障顺序为刹车、侧向转 90°、新测量检查、横移 50cm、恢复原航向前进、转向并横移回线、恢复原航向继续。首选侧被挡只尝试另一侧一次；途中再次遇障停车。超过终点的安全返回点直接提示终点受阻。

`SONAR_AXLE_OFFSET_M=0.14` 是未实测安装参数，`REAR_CLEARANCE_M=0.14` 也需核对实际轮轴位置；地面绕行测试前填写真实值。当前无回波按未发现近障处理，无法判断 Echo 断线；持续高电平、脉宽异常、丢失下降沿与结果超时则停车。

PB21 已经 SysConfig 在 LQFP-64(PM) 下验证，映射为 PINCM49、封装第 20 脚。KEY4 检测页显示 PB10/PB11 原始电平、PA27 电平、Echo 捕获阶段与脉宽、触发次数，用于排查检测灯与 MCU 状态不一致。检测期间始终刹车，KEY1 不启动；KEY3 或再次按 KEY4 退出。具体电平及回环检查见使用说明。

## 构建与验证

Keil 入口：`keil/empty_LP_MSPM0G3507_nortos_keil.uvprojx`。构建前由 `scripts/generate_syscfg.bat` 显式指定 MSPM0G3507、LQFP-64(PM) 生成配置。禁止手改生成文件。

主机自检覆盖：

- `tests/test_square.c`：该文件名沿用原路线测试，内容已改为直行避障、左右绕行、里程投影、角度折返、回线、设置与停车边界。
- `tests/test_board.c`：实际板级代码的寄存器替身，覆盖 PWM、计数、惯导、按键、红外与 Echo 时序。
- `tests/test_oled.c`：实际字库和显存、新页面、I2C 启动延迟、完整刷新及传输故障。
- `tests/test_main.c`：实际主循环与控制集成，覆盖传感器启动门槛、超时停机、停止键和设置时刹车。

测试命令见 `使用说明.md`。当前验证完成到 SysConfig、主机和 Keil 构建层级，未进行实际烧录或实车测试。保留 1024 字节主栈；主机通过不代表电平、刹车、避障间隙或定位误差已经实车验证。
